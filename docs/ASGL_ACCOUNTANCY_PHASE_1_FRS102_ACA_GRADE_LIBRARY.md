# ASGL-A Phase 1 — FRS 102 ACA-Grade Reviewer Guidance Library (Deterministic)

This phase upgrades ASGL-A by adding a structured, deterministic regulations/guidance library for FRS 102,
and wiring it into the existing pipeline and reviewer UI.

## Goals
- Provide reviewer-grade guidance citations without hallucinations
- Ensure findings can be justified via deterministic clause retrieval
- Create a foundation for future phases (FRS 105, FRS 101, Companies Act, ISA prompts)
